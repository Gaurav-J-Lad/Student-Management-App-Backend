- Docker
- Render Deployment

## ✨ Features

- 👤 User Registration & Login
- 🔐 Authentication APIs
- 🛡️ Role-based Backend Structure (Admin/User separation logic)
- 🎓 Create Student Profile linked with User
- 📋 Fetch All Users (Admin Access)
- 📚 Fetch All Courses
- ✏️ Update Student Profile
- ❌ Delete Student Profile
- 🗄️ PostgreSQL Integration
- 🐳 Docker Support
- 🔗 RESTful API Design

## 📌 API Endpoints

### 🔐 Auth APIs

| Method | Endpoint             | Description       |
| ------ | -------------------- | ----------------- |
| POST   | `/api/auth/register` | Register new user |
| POST   | `/api/auth/login`    | User login        |

---

### 🧑‍💼 Admin APIs

| Method | Endpoint                         | Description            |
| ------ | -------------------------------- | ---------------------- |
| POST   | `/api/admin/create-profile/{id}` | Create student profile |
| GET    | `/api/admin/users`               | Get all users          |
| GET    | `/api/admin/courses`             | Get all courses        |
| PUT    | `/api/admin/student/{id}`        | Update student profile |
| DELETE | `/api/admin/student/{id}`        | Delete student profile |
